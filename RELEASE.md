# Repository folders

| Folder | Description |
| --- | --- |
| `checkpoints/` | Trained forward and inverse model weights. |
| `configs/` | Fixed settings for training, evaluation, and inverse design. |
| `data/` | Material data, learning datasets, target spectra, and data splits. |
| `reproducibility/` | Environment files, checksums, and package manifests. |
| `results/` | Numerical results and paper-supporting output tables. |
| `scripts/` | Entry scripts for dataset generation, training, design, analysis, and verification. |
| `src/` | Reusable Python source code for optical modeling and inverse design. |
| `tests/` | Automated structural and numerical tests. |
| `validation/` | Independent-solver and COMSOL comparison data. |
